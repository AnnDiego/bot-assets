# Punchy scenes

Blank photoreal plates. Registered ids in `manifest.json`: `wallet`, `hand`, `cafe`, `fridge`.

JPEG plates (`*.jpg`) are large binaries. If they are missing from this clone, copy them from the working box at `/workspace/punchy/scenes/` or push with `git`/`gh` that supports binary blobs.

Do not commit `synthetic_table.png` (dev-only).
